# Thiranex Social Media Post Design - Task 1

This repository contains the design work and assets for the **Social Media Post Design** task completed for the Thiranex internship.

## 📌 Project Overview
* **Task:** Social Media Post Design
* **Platform:** Thiranex Skill Development & Future Tech
* **Objective:** Create a visually engaging, professional social media post focusing on skill development, career growth, and the value propositions of modern tech learning.

## 🎨 Design Details
* **Tool Used:** Canva
* **Dimensions:** 1080 x 1080 px (Standard Social Media Square)
* **Key Elements Included:**
  * Clean tech-themed background and branding layout
  * Strong headline ("Future-Proof Your Skills")
  * Meaningful value propositions (Industry-Relevant Curriculum, Hands-On Real Projects, Expert Mentor Support)
  * Professional line-art icons and custom call-to-action button
